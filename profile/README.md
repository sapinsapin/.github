# SapinSapin
### Sariling AI Pilipinas

We build data, models, and tools for Philippine-language AI so Filipinos can help shape the technology in their own languages.

SapinSapin is a community initiative working across speech, text, and vision-language AI. Our work connects data collection and preparation with model training, evaluation, and practical deployment.

[Website](https://sapinsapin.ai) · [Models and datasets](https://huggingface.co/sapinsapin) · [Try the speech demo](https://huggingface.co/spaces/sapinsapin/halohalo-dashboard)

## Models and datasets

Our [Hugging Face organization](https://huggingface.co/sapinsapin) hosts speech recognition, speech synthesis, voice conversion, and language models alongside the datasets used to build them.

Start with:

- [Filipino Speech Corpus](https://huggingface.co/datasets/sapinsapin/filipinospeechcorpus), prepared for speech recognition and synthesis.
- [Philippine Language Dataset](https://huggingface.co/datasets/sapinsapin/pld), multilingual speech recordings across ten languages.
- [BantayWika](https://huggingface.co/datasets/sapinsapin/BantayWika), Philippine literary and reference text.
- [Halohalo text corpus](https://huggingface.co/datasets/sapinsapin/halohalo), cleaned and deduplicated web text.

Read each model or dataset card for its license, intended use, and limitations.

## Contribute

Researchers, engineers, native speakers, annotators, and dataset contributors are welcome.

Help prepare data, review transcripts and model outputs, improve evaluation, or build applications using Philippine-language models. Open an issue in the relevant repository with what you want to contribute, or submit a pull request with a focused improvement.

Our goal is to make Philippine languages part of AI’s foundations and give more people the tools to build on them.
